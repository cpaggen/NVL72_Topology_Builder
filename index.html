Plane and rail allocation

Planning model: each rack has 18 compute trays and 72 GPUs. Every GPU has one downlink in each of two separate compute planes. The selected Cisco ToR model sets ToR port capacity; the configured link speeds set bandwidth. Spine capacity uses the separate spine interface count. This planner estimates switch counts and does not reproduce a topology-specific reference-architecture layout.
